# Flight Radar Oracle

An experimental, self-hosted flight-deal monitor built in Python + SQLite, designed for Oracle Cloud Always Free Ampere A1.

> **Status:** source code published; GitHub CI included; **not yet deployed to OCI**. No real-time Google Flights collection has been validated. Do not treat synthetic demo data as genuine fares.

## Capabilities

- Route planning for Belgian, French, Dutch and nearby airports
- SQLite history: comparisons on the same origin/destination, departure/return dates, airline, cabin, stops and declared baggage
- Daily price median baseline, minimum historical evidence (8 distinct days)
- Deal scoring, minimum discount and deduplication
- Manual revalidation of deals before public notification
- Experimental `fast-flights` adapter (unofficial, disabled unless expressly opted in)
- JSON import, local-only dashboard, Telegram alerts
- OCI ARM64 installation, systemd restart, SQLite daily backups, GitHub CI and manual SSH deployment

## Quick start

Requires Python 3.10+ (Python 3.12 recommended). No paid API is necessary for the synthetic demo or JSON imports.

```bash
python -m flight_radar init
python -m flight_radar demo
python -m flight_radar report
python -m flight_radar serve
```

Dashboard: http://127.0.0.1:8080 (binds to loopback; no authentication). Data generated by `demo` is explicitly synthetic.

Run tests:

```bash
python -m unittest discover -s tests -v
```

Import real observations collected from a permitted source:

```bash
python -m flight_radar scan --source json --file fares.json
```

Each JSON element must have `origin`, `destination`, `departure_date`, `return_date`, `price_eur`, `carrier`, `source`; optional `stops`, `cabin`, `baggage`, `link`, `details`, `collected_at`. Dates are ISO `YYYY-MM-DD`. No API key is required for JSON imports.

Experimental Google Flights adapter (only when you have verified applicable access terms):

```bash
python -m pip install -r requirements-optional.txt
python -m flight_radar scan --source fast-flights --allow-unofficial-collection --limit 2
```

It is not guaranteed to work or be allowed for all workloads. It does not bypass anti-bot challenges. **Live price collection is not running automatically.**

## Oracle Cloud

See [Oracle deployment instructions](deploy/oci/README.md). On an existing Ubuntu ARM VM:

```bash
git clone https://github.com/aziriel2020/flight-radar-oracle.git
cd flight-radar-oracle
sudo bash deploy/oci/install.sh
curl http://127.0.0.1:8080/health
```

The installer keeps the dashboard private on the VM at 127.0.0.1:8080; access it using an SSH tunnel. Never expose it directly as a public commercial site without adding HTTPS, authentication and rate limiting. Systemd runs it on reboot; a timer stores consistent SQLite backups locally for 14 days. Off-machine backups are not configured.

GitHub Actions `Deploy to Oracle Cloud (manual)` requires an **existing** VM and four repository secrets: `OCI_HOST`, `OCI_USER`, `OCI_SSH_KEY`, `OCI_SSH_KNOWN_HOSTS`. It does not provision OCI resources or generate credentials.
